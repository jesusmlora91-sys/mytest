# Aplicación Web - Proyecto de Despliegue y Versionamiento

Este repositorio contiene la aplicación web optimizada y la configuración correspondiente para su despliegue en un entorno local simulado Nginx, cumpliendo con los estándares de empaquetado y versionamiento.

## Estructura del Proyecto

```text
primerApp/
├── css/
│   ├── styles.css        # Archivo CSS principal
│   └── styles.min.css    # Versión minificada
├── js/
│   ├── app.js            # Lógica principal en JS
│   └── app.min.js        # Versión minificada
├── img/                  # Recursos de imagen optimizados
├── index.html            # Archivo HTML principal
├── mi-aplicacion.zip     # Paquete comprimido final
├── .gitignore            # Archivos ignorados por Git
└── README.md             # Documentación del proyecto
